# 作品维护说明

编辑仓库根目录内的源文件即可。无需额外构建工具。

## 修改作品

所有作品内容统一保存在 `projects.js`，首页卡片、全部作品页和详情页共用这份数据：

- `name`、`description`：作品名称和描述。
- `card.title`、`card.summary`：卡片标题和简介。
- `card.cover`：卡片封面，含路径、宽高与图片说明。
- `card.category`：全部作品页的筛选分类；分类及数量自动生成。
- `card.order`：全部作品页的排序。
- `hero`、`gallery`：详情首图及后续图片。
- `hidden: true`：从展示列表与详情入口隐藏作品；当前广发易淘金 PC 端、广发智慧数、怒兔保持隐藏。

图片文件在 `assets/` 和 `featured-assets/`。替换图片后同步更新其路径、宽高与说明；新增图片建议用新的文件名，避免缓存继续显示旧图。

## 调整首页精选

编辑 `featured.js` 中的 `FOLIO_FEATURED_IDS` 数组。顺序就是首页显示顺序，当前 5 项为：

1. `jyquants`：JYQuants。
2. `afterlight-archive`：十寸中控屏。
3. `t-home-app`：T home APP。
4. `fieldwork-studio`：广发易淘金国际版。
5. `campaign-2025`：运营 2025 年作品集。

新增作品默认进入全部作品页，需要额外加入此数组才会进入首页精选。首页和列表卡片由脚本生成，不必手工复制 HTML 卡片。

## 添加作品

1. 在 `assets/` 或 `featured-assets/` 放入新图片。
2. 复制 `projects.js` 中格式相近的一条作品记录，填写唯一 `id`、标题、描述、封面和详情图片。
3. 本地打开 `work.html` 确认卡片出现，再打开 `project.html?project=新id` 验证详情。
4. 如需首页展示，将新 ID 加入 `featured.js`。
5. 部署修改的文件和新增图片，并更新 HTML 内对应脚本的 `?v=` 版本参数。

## 修改页面其他部分

| 内容 | 文件 |
| --- | --- |
| 首页文案、个人介绍、经历、联系方式 | `index.html` |
| 首页样式 / 手机适配 | `styles.css` |
| 两页共用头像 / 气泡外观和动效 | `avatar.css` / `avatar.js` |
| 首页菜单 / 动画 / 复制邮箱等交互 | `script.js` |
| 全部作品列表 / 样式 / 筛选与搜索 | `work.html` / `work.css` / `work.js` |
| 详情页模板 / 样式 / 行为 | `project.html` / `project.css` / `project.js` |
| 首页与列表共用的卡片生成逻辑 | `project-cards.js` |

作品页移动端规则集中在 `work.css`：767px 及以下使用两列卡片、14px 标题、12px 简介，隐藏 `.card-meta`，返回首页按钮保持单行。

没有管理后台，以上文件就是完整可编辑源代码。字体再分发时保留 `assets/fonts/Anton-OFL.txt`。
