# 部署说明

本仓库根目录就是静态网站的发布目录，没有额外的构建步骤。

## 上传到静态托管空间

1. 下载或克隆本仓库。
2. 将根目录的 3 个 HTML、3 个 CSS、6 个 JavaScript 文件及 `assets/`、`featured-assets/` 两个文件夹上传到网站根目录。
3. 确认网站根目录直接包含 `index.html`，且素材文件名和相对路径未改变。
4. 在平台提供的网址检查首页、全部作品和各作品详情。

若所选托管平台可以从 GitHub 导入仓库，使用以下项目设置：

| 项目 | 设置 |
| --- | --- |
| 仓库 | `749861561/2026-` |
| 分支 | `main` |
| 框架 | 静态网站 / Other / None，按平台实际选项选择 |
| 项目根目录 | 仓库根目录 |
| 构建命令 | 留空 / 不需要 |
| 发布目录 | `.`，或平台表示仓库根目录的选项 |
| 环境变量、数据库、后端服务 | 均不需要 |

不要设置所有页面回退到 `index.html` 的单页应用重写规则。详情地址形如 `project.html?project=jyquants`，需要正常保留查询参数。

`.git/`、`.gitignore`、README 和 `docs/` 不参与页面运行，不必手动上传。

## 域名与 HTTPS

部署成功后，可在所选平台添加自己的域名，再按平台要求配置 DNS 解析并开启 HTTPS。仓库源码没有绑定特定域名，也没有写入本机文件路径。

## 后续更新

修改 `projects.js` 和 `featured.js` 维护作品内容与首页精选。更换图片建议使用新文件名，修改脚本后同步更新 HTML 中对应的 `?v=` 版本参数，减少旧缓存影响。

若平台未设置自动部署，提交 GitHub 后仍需手动重新部署。上传源码本身不代表网站已上线。

## 素材与现有功能

网站文件共 110 个，约 257 MiB，包含高清作品图和本地字体。保留 `assets/fonts/Anton-OFL.txt` 字体许可证。

网站联系入口使用原有邮箱。详情页简历按钮暂未提供下载文件；需要简历下载时再补充文件并接入按钮。
